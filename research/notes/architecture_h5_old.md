# Архитектура ML-части: подход и модели

## Ключевая идея
Нарушение кассовой дисциплины на видео — это почти всегда **состояние или бездействие** (дверь не закрыта, ПК не заблокирован, ценности оставлены на столе), а не особое движение: те же действия (вход, уход, подход к сейфу) есть и в роликах без нарушений. Поэтому решение — **датчики состояний + правила над таймлайном событий**, а не классификатор действий. Это даёт объяснимость (что именно видно и почему это нарушение) и работу при малом числе примеров.

## Конвейер
```
видео → кадры (2 к/с; видео > 60 с — 1 к/с)
      → D-FINE-S: люди, ноутбук, телефон, сумки, стаканы
      → SIFT + гомография к эталону ракурса: зоны стола, двери, пола (отсекаем людей за стеклом)
      → датчики: створка двери, пятно на столе относительно пустого эталона, яркость экрана
      → трекинг людей и роль кассира
      → правила (дверь, ПК, ценности, телефон, личные вещи, посторонний)
      → гибридный вердикт: главное событие по надёжности; при ненадёжной геометрии
        или признаках визита с передачей — «возможное нарушение» с общим типом
      → JSON: тип, таймкод, кадр-доказательство, описание, норма (справочник rules.json)
```

## Модели и лицензии (все разрешают коммерческое использование)
| Компонент | Модель / библиотека | Лицензия |
|---|---|---|
| Детектор объектов | D-FINE-S, веса на COCO (`ustc-community/dfine-small-coco`) | Apache-2.0 |
| Геометрия | OpenCV SIFT (патент истёк в 2020), гомография MAGSAC | Apache-2.0 |
| Инференс | PyTorch, Transformers | BSD / Apache-2.0 |
Отклонены по лицензии: Ultralytics YOLO (AGPL-3.0), YOLOv7/9/World (GPL), Qwen2.5-VL-3B (research), веса D-FINE на Objects365 (не очищены для коммерции).
Лица не распознаются и не анализируются; звук не используется.

## Локальность
Все модели выполняются внутри сервиса; веса загружаются при сборке образа, при обработке видео интернет не нужен (`HF_HUB_OFFLINE=1`).

## Устойчивость к новому ракурсу
- Ракурс определяется автоматически по SIFT; зоны переносятся гомографией.
- Проверка гомографии (`geometry_ok`); при ненадёжной геометрии зонным правилам не доверяем и выдаём «возможное нарушение» (пропуск дороже ложной тревоги).
- Стресс-тест: все ролики искажены случайной перспективой ±12% — SIFT выровнял 40/40, качество снизилось умеренно (баллы 0.60 → 0.52 по внутренней оценке).

## Как проверяли качество
Собственный оценщик по метрикам жюри (вердикт, таймкод ±2 с, тип) на 33 размеченных роликах, журнал из 20+ A/B-экспериментов (`datathon/experiments.md`), стресс-тест нового ракурса. Подробности — `datathon/`.
