# Интерфейс для сотрудников Forte

Обновлён 18 октября 2026 года. Изменены только статические файлы интерфейса; ML, API, правила и нормативные описания не менялись.

## Сценарий

1. Выбрать подсказки для охранника или менеджера. Это не авторизация и не разграничение доступа.
2. Выбрать или перетащить один MOV до 100 МБ и запустить проверку.
3. Посмотреть результат, кадры и пояснения; при наличии воспроизводимого локального видео перейти к событию по времени.
4. При необходимости раскрыть нормативное основание и отметить просмотренные события. Эти отметки хранятся только в памяти вкладки.
5. Сохранить результат через системную печать/PDF либо сохранить ссылку «Открыть отдельно». В отдельном окне доступны кадры, но не исходное видео.

Кнопка «Новая проверка» очищает текущий экран. Справка доступна во время обработки. При временном сетевом сбое запрос результата можно повторить без новой загрузки. Неизвестная ссылка и ошибка обработки имеют отдельные состояния.

## Проверка

- `node --check service/static/app.js` — успешно.
- Существующие тесты API/сервиса: 24 passed.
- `python service/tests/frontend_smoke.py` — 13 браузерных сценариев, успешно; Chromium, 1440 и 390 px, с политикой CSP сервиса.
- Проверены выбор роли, справка, неверный/пустой файл, неверная замена выбранного файла, drag-and-drop, загрузка, ожидание, результат, текст модели без HTML-инъекций, неподдерживаемый видеокодек, увеличение кадра, нормативный источник, отметки просмотра, печатная верстка, сброс, прямая ссылка, отсутствие событий, неизвестная задача, ошибка обработки и повторный запрос после сетевого сбоя.
- В браузерном тесте ответы API и кадры синтетические и подставляются только через Playwright. Они не встроены в приложение. Качество ML и полный анализ реального видео заново не оценивались.
- Локальный сервис: GET / → 200, /health → ok, ready_workers=5, cleanup_pending=0.

Скриншоты проверки: `service/ui-qa/desktop.png`, `mobile.png`, `result.png`, `result-mobile.png`. Скриншоты результата содержат синтетические тестовые данные.

Первый запуск тестов в ограниченной среде не смог создать временные каталоги/запустить дочерние процессы. Итоговый успешный запуск выполнен с разрешёнными локальными процессами и отдельным временным каталогом внутри workspace.
