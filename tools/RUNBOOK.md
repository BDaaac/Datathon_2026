# Запуск сервиса для жюри (ноутбук + Cloudflare Tunnel)

Окно проверки: **12:00–14:30**. Всё это время ноутбук включён, окна сервиса и туннеля открыты.

## Перед запуском (вручную)
- **Зарядка подключена** (без неё батареи не хватит).
- Крышку не закрывать. Если закрыть нужно: Параметры → Система → Питание → «Действие при закрытии крышки» → «Ничего не делать».
- Сон Windows отдельно отключать не обязательно: пока открыто окно «Forte · сервис», оно само запрещает системе засыпать. Экран гаснуть может.
- Стабильный интернет (лучше кабель). От скорости приёма зависит загрузка видео жюри.

## Запуск — только двойным кликом
Откройте папку проекта и дважды кликните **`START_SERVICE.bat`**.

Скрипт сам:
1. остановит старые копии сервиса и туннеля;
2. откроет окно **«Forte · сервис»** (перезапускает сервис при падении, запрещает сон);
3. откроет окно **«Forte · туннель»** (публичный адрес, перезапуск при обрыве);
4. проверит, что публичный адрес отвечает, и покажет адреса для формы. Адрес копируется в буфер обмена и сохраняется в `tools\PUBLIC_URL.txt`.

**Не запускайте сервис из Claude или другого инструмента**: процессы, запущенные агентом, завершаются вместе с его командой (проверено 18.10 в 04:11).

## Что вписать в форму
| Поле | Значение |
|---|---|
| Web interface URL | адрес из окна запуска (`https://….trycloudflare.com`) |
| API base URL | тот же адрес + `/api/v1` |
| API key | `SERVICE_API_KEY` из `service\.env` |

## Проверка
Откройте `<адрес>/health` в браузере — должно быть `"ready_workers":5`. `<адрес>/api/v1` показывает справку по API.

## Если что-то упало
- **Сервис упал** — окно «Forte · сервис» поднимет его само (до ~2 минут). Адрес не меняется.
- **Окно «Forte · сервис» закрыли** — двойной клик по `RESTART_SERVICE_ONLY.bat`: поднимет только сервис, туннель и адрес останутся прежними.
- **Туннель оборвался** — окно «Forte · туннель» перезапустит его, но **адрес изменится**: новый будет в окне туннеля и в `tools\PUBLIC_URL.txt`. Сразу сообщите организаторам.
- **Закрыли окна / перезагрузили ноутбук** — снова двойной клик по `START_SERVICE.bat`, новый адрес сообщить организаторам.

## Измерено 18.10
- 5 параллельных загрузок самого длинного видео (143 с, 27 МБ) через публичный адрес из Kaggle: все готовы, максимум 189 с (лимит 300), из них ~86 с — загрузка.
- Детектор: onnxruntime (CPU), 5 ML-процессов, ~0.7 ГБ RAM на процесс.
- Автоперезапуск: после принудительного падения сервис поднялся сам за 122 с.
