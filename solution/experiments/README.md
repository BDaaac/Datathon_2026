# Отклонённые эксперименты (архив)
Скрипты экспериментов, которые не вошли в модель. Итоги — в `research/notes/experiments.md`.
Запускать из папки `solution/` (скрипты ожидают `decide.py`, `bench.py` рядом): `python experiments/<имя>.py`.

| Скрипт | Эксперимент | Итог |
|---|---|---|
| vlm_probe.py, vlm_cashier.py (+ vlm_cashier.jsonl) | Qwen3-VL-2B: телефон на кропе кассира | купюры = «телефон», 31 с/кадр CPU — отклонён |
| phone_crops.py | кропы кандидатов телефона из детекций | детектор не находит телефон в роликах-нарушениях — отклонён |
| pose_probe.py | RTMPose (rtmlib) лицензия и скорость | быстро, но лицензия весов серая — не взят |
| hcheck.py | гигиена гомографии | ничего не отсекает (ракурсы близки) — отклонён |
| blob_self.py | эталон стола из самого ролика | не разделяет классы — отклонён |
| visit_features.py, visit_model.py (+ visit_features.csv) | модель «подозрительности визита», leave-one-out | не лучше «только датчиков» — отклонён |
